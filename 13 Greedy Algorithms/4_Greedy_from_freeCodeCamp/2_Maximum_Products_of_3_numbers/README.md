# Highest Product of Three Elements

**Difficulty:** Easy

**LeetCode:** https://leetcode.com/problems/maximum-product-of-three-numbers/

## Problem Statement

Given an array of `N` integers, find the highest product possible by multiplying 3 elements of the array.

## Examples

### Example 1

```
Input: nums = [1, 2, 3, 4]
Output: 24
Explanation: 2 * 3 * 4 = 24
```

### Example 2

```
Input: nums = [0, -1, 10, 7, 5]
Output: 350
Explanation: 5 * 7 * 10 = 350
```

### Example 3

```
Input: nums = [-10, -10, 5, 2]
Output: 500
Explanation: (-10) * (-10) * 5 = 500
```

## Constraints

- `3 <= N <= 5 * 10^5`
