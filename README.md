# # Striver DSA Sheet

This repository contains my solutions to the **Striver A2Z DSA Sheet** in **C++**, organized topic-wise from basic to advanced.

The main objective of this repository is to build strong problem-solving skills, master Data Structures & Algorithms, and prepare for coding interviews through consistent practice. The repository follows the learning path of the **Striver A2Z DSA Sheet**.

---

## # Highlights

-  Topic-wise solutions following the **Striver A2Z DSA Sheet**
-  Solutions written in **C++**
-  Clean, optimized, and easy-to-read code
-  **Almost every important question contains detailed comments** explaining the intuition, approach, and logic for better understanding.
-  Great for revision and interview preparation
-  Repository is updated regularly as I progress through the sheet
